# 概述

**OmniKit** 是面向 [思源笔记（SiYuan Note）](https://b3log.org/siyuan/) 的工具箱插件，提供自动标题链接、图片压缩与外链图片转存等功能。插件采用模块化设计，各个功能模块相互独立，用户可在设置面板中根据需要单独开启或关闭。

---

# 功能列表

## 1. 自动标题链接 (Titled Link)

在编辑器中粘贴网址时，后台异步获取对应网页标题并写入超链接文本。

- **自动获取网页标题**：在正文中粘贴单个网址、包含多个网址的文本段落或富文本链接（由思源设置自动转链接或剪贴板带入的 `http://` / `https://` 超链接且无自定义显示文字）时，后台异步请求网页并提取 `<title>`，自动填入超链接的锚文本（显示文字）。
- **保护用户自定义文本与选区语义**：若粘贴内容为已包含标题的 Markdown/富文本链接（例如 `[标题](url)`），或链接显示文字已被手动修改，插件不作改写；选中已有文本并直接粘贴单个裸 URL（为选中文本加超链接）时也会保留原选中文本，跳过自动提取；选区替换粘贴含 URL 的文本段落时则正常处理新链接。
- **静态文件链接识别**：对于指向常见非网页文件（如 `.pdf`、`.zip`、`.exe` 等）的链接，直接从 URL 中提取并解码文件名作为显示文字，不发起网络请求。
- **右键菜单操作**：
  - 右键单个链接，选择 `[OmniKit] 提取链接标题`，可手动触发重新抓取；
  - 右键内容块图标，选择 `[OmniKit] 批量提取链接标题 (共 N 个)`，可对当前块内的所有 HTTP/HTTPS 超链接进行批量提取。
- **活动编辑器撤销**：原编辑器仍处于打开状态时，标题填入通过思源原生事务执行，可使用 `Ctrl+Z` 撤销；若原编辑器已关闭而转为后台内核写回，则不保证进入编辑器撤销栈。

## 2. 图片压缩与外链转存 (Image Compressor)

提供图片转换为 WebP 格式压缩以及网络外链图片转存到本地资源目录的能力。

- **新插入图片自动压缩**：在笔记中粘贴或拖入图片时，后台自动转换为 WebP 格式保存。支持设置为全局生效，或仅对白名单中的指定文档生效；可在文档树右键、文档标题右键或顶栏菜单中通过「当前文档图片自动压缩白名单」勾选切换（白名单独立维护，不受全局开关状态覆盖）。
- **单张图片手动压缩与预览**：
  - 右键编辑器中的图片，选择 `[OmniKit] 压缩此图片` 可直接转换为 WebP；
  - 选择 `[OmniKit] 压缩…` 可打开微调预览弹窗，支持调节压缩质量参数，实时查看前后体积对比与预览效果，并可选择仅保存产物或替换正文引用。
- **文档批量压缩**：在文档树或编辑器顶部标题右键选择 `[OmniKit] 压缩当前文档全部图片`（或在顶栏菜单选择「压缩当前文档全部图片」），批量处理当前文档内的全部图片。
- **外链图片自动转存**：在已授权文档中自动识别新插入的外部 HTTP/HTTPS 图片链接，下载并保存为思源本地 `assets/` 附件资源。
- **压缩记录面板与引用还原 (Dock)**：
  - 点击思源侧边栏（Dock）的 OmniKit 图标打开记录面板，可查看原图与最新压缩图的对应关系及资产状态；
  - 支持从记录项点击跳转并高亮文档中的对应图片块；
  - 支持将文档中的压缩图引用恢复为原图引用。

# 使用与设置

1. 点击思源顶栏的 OmniKit 图标，选择「OmniKit 设置」打开设置面板；
2. 通用设置、功能启用开关及各功能专属参数统一在界面草稿中编辑，通过底部的全局浮动操作栏点击「保存设置」或「恢复默认值」统一生效（不会直接修改独立配置文件之外的业务记录）；
3. 支持的配置项：
   - **通用设置**：控制台调试日志开关、全局网络请求 `User-Agent`；
   - **图片压缩**：全局自动压缩开关、文档白名单、智能压缩开关（基于 MS-SSIM 相似度自适应寻优）、目标相似度、起始质量、手动压缩最大边长；
   - **自动标题链接**：粘贴时自动提取链接标题、同步写入悬浮标题属性（`data-title`）、拉取失败时降级为网站域名（标题长度固定按 80 个字素截断）。

# 安全机制

- **原始图片保留**：转换生成的 WebP 图片作为新资源保存至 `assets/`，插件不执行物理删除用户原始附件的操作；
- **零工作区垃圾文件**：不在思源工作区内写入临时日志、队列缓存或 `.tmp` 临时文件；
- **写前一致性核验**：执行正文内容替换前校验目标块与节点状态，若检测到并发编辑冲突则放弃改写，保障文档内容安全。

# 安装方式

- **方式一：思源集市安装（推荐）**  
  在思源笔记中打开 **设置 -> 集市 -> 插件**，搜索 `OmniKit` 并点击下载启用。
- **方式二：手动安装**  
  前往 [Releases 页面](https://github.com/Forgo7ten/siyuan-plugin-omnikit/releases) 下载 `package.zip`，解压至思源工作空间插件目录 `data/plugins/siyuan-plugin-omnikit/`，重启思源笔记。

# 开发与构建

### 环境要求
- Node.js >= 24.0.0
- pnpm >= 11.4.0
- 思源笔记 >= 3.8.4

### 常用命令
```bash
# 安装依赖
pnpm install

# 类型检查与单元测试
pnpm check
pnpm test

# 构建生产产物
pnpm build
```
