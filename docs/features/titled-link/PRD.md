## 1. 功能定位与产品边界

### 1.1 核心目标
OmniKit 自动标题链接功能可读取网页标题，并将其写入思源正文超链接的显示文字：
1. 思源正文超链接包含显示文字（锚文本）、链接地址和悬浮标题。默认只更新显示文字；开启“同时替换悬浮标题属性”后，也更新悬浮标题属性，不修改链接地址；
2. 用户粘贴 URL 后，思源先完成原生粘贴。插件在后台读取网页标题，不影响继续输入或编辑器焦点；
3. 插件只更新用户点击的链接，或本次粘贴产生的链接，不搜索并替换文档中的其他相同地址；
4. 触发该任务的原编辑器仍打开且未销毁时，通过思源编辑事务更新链接，支持 `Ctrl+Z` / `Ctrl+Y` 撤销和重做；当原编辑器已关闭或不可用时，插件在后台执行块更新（写入前核验块归属、目标链接与剔除只读渲染属性后的整块内容基线，与任务开始时记录不一致时跳过更新；后台更新不保证能通过当前编辑器的撤销和重做操作恢复）；
5. 桌面版直接请求网页，最多读取 64KB，读到 `</head>` 后停止；浏览器和移动端通过思源内核请求网页并读取前 64KB。所有平台使用插件通用设置中的 `User-Agent`。插件识别 GBK、Big5、Shift-JIS、UTF-8 等字符编码，读取 HTML 标题并还原 HTML 实体。遇到非网页文件时不发起网页标题请求；读取失败时可显示网站域名；
6. 缓存只保存在内存中，不向工作区写入临时文件或待处理任务文件。写回前检查目标块和链接；如果编辑尚未保存、整块或目标链接内容已被修改或链接已删除，则不执行后台更新。

### 1.2 功能边界 (Scope)

| 维度 | 包含 | 不包含 |
|---|---|---|
| **改写对象** | 思源正文块内原生可编辑的行内超链接锚文本（显示文字）；开启“同时替换悬浮标题属性”时同步改写悬浮标题属性 | 链接地址、未开启“同时替换悬浮标题属性”时的悬浮标题属性、链接卡片、数据库/属性视图对象、只读块、代码块、数学公式 |
| **网络协议** | 仅校验 `http://` 与 `https://` 格式；默认笔记内 URL 可信 | `mailto:`、`file:`、`ftp:`、`siyuan://`、`javascript:`、相对路径、无协议前缀地址 |
| **非网页文件** | 对常见归档、安装包、文档、媒体和图片链接直接提取文件名，不发起网页请求 | 请求大型安装包或压缩文件并尝试将其作为网页解析 |
| **触发方式** | 1. 粘贴后自动提取（监听粘贴范围或新插入块中的合格超链接节点，支持单个 URL、多行多段落多 URL 文本及富文本自带超链接）；<br>2. 链接右键菜单；<br>3. 块图标菜单中的批量提取（同时请求最多 3 个链接） | 扫描已有笔记中的全部链接；定时抓取；跨文档批量重命名 |
| **内容解析** | 静态 HTML 流式解析（读取前 64KB，`<title>` -> `og:title` -> `twitter:title`）；多字符集编码识别；HTML 实体还原；长标题截断；拉取失败降级网站域名 | 动态 JavaScript 执行、SPA 页面渲染、正文内容抓取、AI 总结生成标题 |
| **反爬页过滤** | 完整匹配 `Just a moment...` 及其大小写/省略号变体过滤挑战页 | 复杂网站反爬黑名单系统、登录页破解、验证码绕过、付费墙穿透 |
| **并发与通知** | 每次自动粘贴处理结束后发送一条结果汇总通知（单链接反馈单链结果，多链接汇总提示）；手动提取显示结果；块级批量提取最多同时请求 3 个链接，并在结束后显示一条汇总通知 | 为批量处理的每个链接分别弹窗提示 |
| **平台覆盖** | 桌面版（Windows、Mac、Linux）、桌面窗口版、桌面浏览器、移动应用、手机浏览器 | - |

## 2. 自动提取链接标题的条件和过程

### 2.1 自动提取过程
- **先完成粘贴**：用户粘贴内容时，思源先按原有方式插入内容，插件不拦截或延迟插入；
- **超链接生成来源与思源设置**：纯文本网址是否转换为超链接由思源设置【行为】->【粘贴网址时自动转为链接】决定，插件不自行将纯文本 URL 转换为链接，也不在入口处预先拦截；插件统一等待粘贴插入与编辑事务提交后，检查本次粘贴范围内实际生成或剪贴板富文本带入的合法 `http://` 或 `https://` 超链接节点，未出现合格超链接节点时静默跳过；
- **粘贴范围与多链接处理**：插件等待本次粘贴内容插入编辑器并提交编辑事务后，仅检查本次粘贴范围或新插入块内的超链接节点（支持单个 URL、包含普通文字与多个 URL 的多行/多段落文本，以及剪贴板富文本带入的超链接），不扫描粘贴范围之外的既有旧链接；若粘贴范围或目标块无法唯一定位（如锚点歧义或编辑器已销毁），直接安全跳过；
  - **自动提取条件**：只有目标链接的显示文字为空（`""`）或与 URL 相同（`anchorText === href`）时，才自动读取网页标题；
  - **非空选区与自定义文字保护**：
    - 粘贴前存在非空选区、且剪贴板内容为单个裸 URL 时，用户意图为已有选中文本添加超链接，插件跳过自动提取；
    - 粘贴前存在非空选区、且剪贴板内容为包含 URL 的文本段落（替换原有选区内容）时，按上述规则排查粘贴范围内新产生的超链接并自动提取标题；
    - 已有标题的 Markdown 链接（例如 `[思源笔记](https://b3log.org/siyuan)`）或粘贴后已被用户修改显示文字的链接，系统直接跳过，绝不覆盖用户自定义内容；
  - **避免更新到错误链接**：同一块内原本已有相同 URL 时，仅处理本次粘贴范围新增的链接实例，不误改既有旧链接；
- **更新前检查**：网页返回后，再检查目标链接。链接未变化时，只更新该链接的显示文字并通过思源编辑器事务提交；如果链接已变化或编辑器状态不允许写入，则跳过更新；
- **按块分组与最小块提交**：每次只改写包含目标链接的最小可写块，不提交其他未变化块或整篇文档；同一块内有多个新链接时，按块合并在一次块级安全写入中一并提交；不同块分别提交；目标块内非目标链接与其他文字保持原样；
- **后台更新前检查整个块**：以触发该任务的原编辑器为准；若原编辑器仍打开且未销毁，通过编辑器事务提交。原编辑器关闭或不可用时走后台更新，写入前重新读取目标块并剔除只读渲染属性，核验块归属、目标链接以及整块内容基线是否与任务开始时一致；如果编辑尚未保存或内容已变化导致不一致，判定冲突并跳过更新。后台写入收到内核成功确认即视为已保存，不额外重读。

### 2.2 不请求非网页文件
对于指向非网页文件或媒体文件的链接，插件不请求网页，直接从 URL 中提取文件名作为链接显示文字：
1. **覆盖的文件类型矩阵**：
   - **归档与安装包**：`.zip`, `.rar`, `.7z`, `.tar`, `.gz`, `.exe`, `.dmg`, `.pkg`, `.apk`, `.deb`, `.rpm`, `.iso`；
   - **办公文档与电子书**：`.pdf`, `.docx`, `.xlsx`, `.pptx`, `.doc`, `.xls`, `.ppt`, `.epub`, `.mobi`；
   - **音视频媒体**：`.mp4`, `.mkv`, `.avi`, `.mov`, `.wmv`, `.flv`, `.mp3`, `.wav`, `.flac`, `.aac`, `.m4a`；
   - **图片资产**：`.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`, `.gif`, `.bmp`, `.ico`；
2. **提取算法**：
   - 提取 URL 路径（Pathname）的最后一段（剥离 Query 参数与 Hash 锚点）；
   - 尝试执行标准 URL 解码，将百分号编码文件名还原为人类可读文件名；即使解码失败，也不发起网页请求，直接回退使用原始文件名字符串；
   - 如果提取出的文件名有效且非空，将其用作链接显示文字，并按第 3.3 节清理字符、压缩空白和限制长度；之后不请求网页。

- **自动提取提示**：每次有实际处理对象的自动粘贴（包含单链接与多链接粘贴）完成后发送一条汇总通知（单链接反馈单链结果，多链接汇总提示）；未产生合格超链接或被跳过时不显示提示；用户通过右键菜单手动提取时显示处理结果；
- **编辑器和输入法**：标题在后台读取，不移动编辑器焦点或更改链接外的选区。若目标编辑器正在使用输入法输入，暂缓更新并轮询等待输入法结束（轮询间隔 500ms，超时上限 5 秒；避免过短轮询占用 CPU）；若等待 5 秒仍未结束，取消本次更新并独立反馈提示“用户正在输入，等待超时，已取消更新链接标题”（不归类为链接内容冲突）；分屏时只检查目标链接所在的编辑器。光标位于该链接内时，更新后将光标放在新标题末尾；
- **不符合条件时停止检查**：本次粘贴范围内未产生或带入合格的 `http://` / `https://` 超链接节点时，静默结束且不请求网页。

## 3. 标题来源、挑战页处理和文字清理

### 3.1 标题选取优先级
1. **第一优先级**：`<head><title>` 标签内的文本内容；
2. **第二优先级**：`<meta property="og:title" content="...">` 属性值；
3. **第三优先级**：`<meta name="twitter:title" content="...">` 属性值；
4. 标题只从 `<head>...</head>` 中读取，最多读取 64KB；遇到 `</head>` 后停止。读取到 `</title>` 时继续查找，以便在 `<title>` 为空时仍能读取 `og:title` 或 `twitter:title`。页面没有 `<head>` 时，只读取 `<body>` 之前的内容，并跳过内联 `<svg>` 中的 `<title>`。

### 3.2 反爬挑战页过滤与降级策略
- **挑战页识别**：如果页面标题为 `Just a moment...` 或其省略号变体，忽略该页面，使标题候选不采用该页的 `og:title` 或 `twitter:title`；
- **拉取失败降级网站域名**：当网络请求失败、超时、命中反爬拦截、或 HTML 中未包含任何可用标题时：
  - 若开启“拉取失败时降级为网站域名”（默认开启），提取原 URL 的域名主机名（例如 `github.com`、`b3log.org`）并经过第 3.3 节统一的空白/控制字符清理与长度上限截断后作为降级标题回填；
  - 若关闭“拉取失败时降级为网站域名”，则判定为提取失败，完全保留原 URL，不执行修改。

### 3.3 标题净化与长度截断
1. **还原 HTML 实体**：将标题中的 HTML 实体和 Unicode 数字实体转换为对应字符；
2. **空白字符压缩**：将所有连续 Unicode 空白字符（含换行符 `\r`、`\n`、制表符 `\t`、半角空格、全角空格、不间断空格等）统一压缩替换为单个半角空格，并去除首尾空白；
3. **字符和长度限制**：网页标题、文件名和网站域名都应用相同规则：标题最大长度在代码中固定为默认常量 80 个字素（仅通过修改代码调整，不提供设置界面或配置字段）；去除 C0/C1 控制字符、双向控制字符及零宽空格（`\u200B`），但保留 `\u200C`、`\u200D`；文本长度不超过上限（80 个字素）时不截断，超过上限时截断——上限不超过 3 时直接截取对应长度且不追加 `...`，上限超过 3 时保留 `上限 - 3` 个字素并追加 `...`；
4. **标题没有变化时不更新**：清理后的标题与当前链接显示文字相同，且开启“同时替换悬浮标题属性”时悬浮标题也相同，则不提交修改。

## 4. 菜单动作与用户交互

### 4.1 单链接手动提取
- **入口**：在正文块内对 `http://` 或 `https://` 行内超链接点击右键（桌面端）或长按（移动端）弹出的链接上下文菜单（非 HTTP/HTTPS 协议如 `mailto:`、`siyuan://` 不展示该菜单项）；
- **行为**：绕过短期内存缓存发起强制联网请求并覆盖锚文本（无论当前链接是否已有自定义锚文本）；拉取失败降级为域名时，不将该降级域名写入短期内存缓存；
- **反馈**：耗时超过 1 秒时展示非模态提示；成功更新、标题已是最新、失败降级均有轻量状态反馈；确定写入失败、内容冲突与结果未知分别反馈。

### 4.2 块级批量提取
- **入口**：在块图标菜单中，若当前块（或包含的子块）中存在 1 个及以上 `http://` / `https://` 行内超链接，挂载菜单项；
- **动态数量感应**：菜单标题实时计算并渲染链接数量，例如“批量提取链接标题 (共 3 个)”；
- **受控并发、进行中去重与聚合回写**：最大并发网络请求数限制为 3；对同一块的重复并发批量触发执行进行中的批量任务去重，避免重复点击叠加执行；批量提取不读写短期内存缓存（进行中的相同 URL 请求共享去重结果）；同块内所有链接拉取完成后，在单次事务中一并提交；
- **聚合单条通知**：全部链接处理完成后，发送单条聚合结果汇总；若全部项均被取消或取代，则静默结束不发送通知。

### 4.3 单链与批量写入结果确认
- 后台写入收到内核成功确认即视为已保存，不额外重读。可确认的目标块内容冲突归类为内容冲突，可确认的写前阻断或内核明确拒绝响应归类为处理失败；仅当写请求已发出但因超时、断连或等待响应阶段被中止而结果未知时，归类为结果未知，随后重新读取目标块核实结果，禁止直接重发写请求。
- 重读确认目标标题已更新时按成功处理；重读确认目标被用户改动时归类为内容冲突；写请求结果未知后的重读即使仍看到旧内容，因在途请求仍可能稍后生效，不构成确定失败证据，仍保留结果未知且禁止自动重试；只有获得确定失败证据时才归类为处理失败。
- 块级批量汇总内部守恒统计：成功（包含实际更新与已是最新）、内容冲突（仅真实目标或块基线不一致）、处理失败（确定失败；输入法等待超时独立统计，不归为内容冲突）、结果未知与已取消/已取代（不计入失败），确保各分类之和等于总数；面向用户的汇总通知必显总数，其余分项（含成功及已更新/已是最新子项、内容冲突、处理失败、输入法等待超时、结果未知与已取消/已取代）仅在数量大于 0 时动态拼接展示；单链接手动提取结果未知时给出对应核实反馈。

## 5. 设置项结构与界面规范

设置保存在插件独立的功能配置文件中（网络请求 User-Agent 统一复用插件通用设置，本功能不单设独立 User-Agent 选项）：
- **粘贴时自动提取链接标题**：默认开启；副标题优先从思源运行期语言词典读取对应设置分组与开关名称，不可读时回退至插件内置文本（中文回退：`需同时开启思源设置：【行为】->【粘贴网址时自动转为链接】`）；
- **同时替换悬浮标题属性**：默认关闭；
- **拉取失败时降级为网站域名**：默认开启。

*(标题最大长度固定为默认常量 80 个字素，不提供用户设置项。)*

## 6. 后续规划功能

1. **支持更多网站**：为 GitHub Issue/PR、Bilibili 视频、知乎专栏等网站提取更适合该网站的标题；
2. **链接图标（Favicon）自动补充**：在用户配置允许下，探索为行内链接自动补充网站 Favicon 徽标；
3. **失效链接检查**：检查已有笔记中的链接是否可访问，并在发现失效链接时提示用户。
