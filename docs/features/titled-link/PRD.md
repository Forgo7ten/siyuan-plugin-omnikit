## 1. 功能定位与产品边界

### 1.1 核心目标
OmniKit 自动标题链接（Titled Link）功能为思源笔记提供安全、异步、无侵扰的行内超链接标题获取与文本替换能力：
1. **以锚文本改写为核心**：思源笔记中的超链接以 `<span data-type="a" data-href="http://..." data-title="...">锚文本</span>` 结构持久化存储。本功能默认仅替换该元素内部的“锚文本”（显示文字）；同时提供可选设置项允许同步更新悬浮标题属性（`data-title`），链接地址（`data-href`）保持不变；
2. **非阻塞异步处理**：用户粘贴 URL 时保持思源原生插入流程正常完成，网页请求与标题解析在后台异步进行，不阻塞用户连续输入或抢夺编辑焦点；
3. **改写范围精确锁定**：每次操作严格锁定被点击或本次独立粘贴创建的唯一目标行内超链接实例（最小副作用原则），不执行全局字符串搜索替换，不产生跨文档或同块其他相同 URL 的副作用；
4. **原生受控事务与撤销支持**：通过受控的思源编辑器事务队列，原生支持 `Ctrl+Z` / `Ctrl+Y` 撤销与重做，保持块级历史版本一致性；
5. **双轨网络分流与流式解析保护**：桌面客户端（`desktop` / `desktop-window`）直连网络请求并在读取至 64KB 上限或匹配 `</head>` 闭合标签时主动取消底层网络流；浏览器端与移动端通过思源内核代理转发并截取前 64KB 字节流执行解析；网络请求统一复用 Core 平台全局 User-Agent 配置；具备多字符集自动嗅探（GBK/Big5/Shift-JIS/UTF-8 等）以正确解析多语言网页标题；支持 HTML 实体还原、非网页文件免抓取与失败降级网站域名；
6. **零工作区污染与数据安全**：纯内存短期驻留缓存，不向工作区写入任何临时调试或排队文件；写前核验目标节点，遇到并发编辑冲突或节点移除时安全放弃改写，保留用户当前编辑内容。

### 1.2 功能边界 (Scope)

| 维度 | 纳入范围 (In-Scope) | 排除范围 (Out-of-Scope) |
|---|---|---|
| **改写对象** | 思源正文块内原生可编辑的行内超链接锚文本（显示文字）；开启 `replaceTitle` 时同步改写 `data-title` 属性 | 链接地址（`data-href`）、未开启 `replaceTitle` 时的 `data-title` 属性、链接卡片、数据库/属性视图对象、只读块、代码块、数学公式 |
| **网络协议** | 仅校验 `http://` 与 `https://` 格式；默认笔记内 URL 可信 | `mailto:`、`file:`、`ftp:`、`siyuan://`、`javascript:`、相对路径、无协议前缀地址 |
| **文件免抓取** | 常见非网页文件扩展名（归档、安装包、文档/媒体、图片等）直接提取文件名并解码，零网络请求 | 试图对大体积二进制安装包或压缩文件发起 HTTP 请求并解析 HTML |
| **触发方式** | 1. 独立粘贴 URL 异步自动触发（满足锚文本门槛与 100~300ms 延迟）；<br>2. 单链接上下文菜单；<br>3. 块级批量提取上下文菜单（受控并发度 3） | 存量笔记全库扫描、定时后台轮询抓取、跨文档批量重命名 |
| **内容解析** | 静态 HTML 流式解析（读取前置 32KB~64KB，`<title>` -> `og:title` -> `twitter:title`）；多字符集自动嗅探；HTML 实体还原；长标题截断；拉取失败降级网站域名 | 动态 JavaScript 执行、SPA 页面渲染、正文内容抓取、AI 总结生成标题 |
| **反爬页过滤** | 完整匹配 `Just a moment...` 及其大小写/省略号变体过滤挑战页 | 复杂网站反爬黑名单系统、登录页破解、验证码绕过、付费墙穿透 |
| **并发与通知** | 自动模式彻底无感静默；单链手动即时反馈；块级批量受控并发并在全部完成时聚合汇报单条通知 | 自动提取弹窗打扰；块级提取为每个链接逐个弹窗轰炸 |
| **平台覆盖** | `desktop`（Win/Mac/Linux）、`desktop-window`、`browser-desktop`、`mobile`（App）、`browser-mobile`（手机浏览器） | - |

## 2. 自动提取时序与准入策略

### 2.1 异步处理时序与门槛校验
- **原生粘贴先行**：用户在编辑器中粘贴内容时，插件优先放行思源原生粘贴逻辑，不拦截事件、不延迟插入，毫秒级生成初始行内链接；
- **剪贴板纯文本修整与单 URL 判定**：用户从外部复制链接时，剪贴板末尾常附带换行或空白字符；系统在粘贴检测时对纯文本进行首尾空白修整，只要修整后为单一合法的 `http://` 或 `https://` 链接且不包含内部换行，即允许进入候选提取；
- **延迟检查门槛（100~300ms 防抖）**：原生粘贴完成后，插件延迟 100~300ms 检查生成的链接节点：
  - **自动触发门槛**：仅当链接节点的锚文本为空（`""`）或等于原 URL（`anchorText === href`）时，才自动触发后台抓取；
  - **自定义保护**：若用户已在外部复制了带标题的 Markdown 链接（例如 `[思源笔记](https://b3log.org/siyuan)`）、粘贴前存在文本选区、或在延迟期间已输入自定义锚文本，系统直接跳过，绝不覆盖用户自定义内容；
  - **同块相同 URL 防歧义短路**：当当前块内已存在相同 URL 的超链接且发生重新渲染导致节点模糊时，系统主动跳过自动提取，防止歧义替换；
- **思源原生设置依赖**：若思源原生“粘贴 URL 自动转链接”设置处于关闭状态，插件始终跳过自动提取，不强制改变用户排版；
- **写前比对防护**：网络返回后，执行写前节点比对核验。核验通过后局部修改锚文本并提交受控事务；若发生内容修改或焦点冲突，系统安全放弃回填。

### 2.2 非网页文件扩展名免抓取机制
对于指向非网页文件的直接下载链接或媒体链接，无需发起耗时且无意义的 HTTP 网络请求，系统直接截取 URL 路径末尾的文件名作为锚文本：
1. **覆盖的文件类型矩阵**：
   - **归档与安装包**：`.zip`, `.rar`, `.7z`, `.tar`, `.gz`, `.exe`, `.dmg`, `.pkg`, `.apk`, `.deb`, `.rpm`, `.iso`；
   - **办公文档与电子书**：`.pdf`, `.docx`, `.xlsx`, `.pptx`, `.doc`, `.xls`, `.ppt`, `.epub`, `.mobi`；
   - **音视频媒体**：`.mp4`, `.mkv`, `.avi`, `.mov`, `.wmv`, `.flv`, `.mp3`, `.wav`, `.flac`, `.aac`, `.m4a`；
   - **图片资产**：`.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`, `.gif`, `.bmp`, `.ico`；
2. **提取算法**：
   - 提取 URL 路径（Pathname）的最后一段（剥离 Query 参数与 Hash 锚点）；
   - 执行标准 URL 解码，将百分号编码文件名还原为人类可读文件名；
   - 若提取出的文件名有效且非空，直接将其作为目标标题回填（同样经过第 3.3 节统一的危险控制符清洗、空白压缩与 `maxTitleLength` 长度截断），跳过网络请求与流式解析流程。

### 2.3 彻底无感静默与低开销规范
- **彻底无感静默**：自动提取执行过程中与结束后，无论是成功替换、文件免抓取回填、抓取超时、网络错误、反爬拦截还是准入跳过，系统完全静默处理，严禁弹出任何气泡打扰用户正常写作；仅在手动模式（单链右键提取或块级批量提取）下向用户提供明确的交互反馈；
- **输入环境与目标编辑器级 IME 保护**：标题回填全程在后台完成，严禁抢夺当前编辑器焦点或破坏用户在链接外部正在编辑的选区；输入法组合输入（IME）状态按目标编辑器实例独立追踪，仅当目标链接所属编辑器处于 IME 组合态时暂缓或保护写回（分屏场景下另一编辑器中的 IME 组合不阻塞目标编辑器写回）；仅当折叠光标正位于当前被替换的行内链接内部时，随锚文本更新保持光标停留在新标题末尾（不回跳至链接开头）；
- **尽早短路**：若剪贴板内容不符合单 URL 判定，或原生设置未启用，监听器立即同步退出，绝不在未命中场景下发起任何网络请求或 DOM 轮询。

## 3. 标题优先级、反爬过滤与归一化

### 3.1 标题选取优先级
1. **第一优先级**：`<head><title>` 标签内的文本内容；
2. **第二优先级**：`<meta property="og:title" content="...">` 属性值；
3. **第三优先级**：`<meta name="twitter:title" content="...">` 属性值；
4. 标题解析在 `<head>...</head>` 头部区域（流式读取持续至 `</head>` 闭合标签或 64KB 上限，不因提前遇到 `</title>` 而截断，确保 `<title></title>` 之后的 `og:title` / `twitter:title` 仍可作为回退候选）内进行匹配；若页面缺少 `<head>` 则截取 `<body>` 之前片段并排除内联 `<svg>`，杜绝正文内联 SVG 中的 `<title>` 等无障碍文本误伤。

### 3.2 反爬挑战页过滤与降级策略
- **挑战页整页过滤**：精准完整匹配 `Just a moment...` 及其省略号变体，一旦命中整页拒绝，坚决不回退到 `og:title` 或 `twitter:title`；
- **拉取失败降级网站域名**：当网络请求失败、超时、命中反爬拦截、或 HTML 中未包含任何可用标题时：
  - 若设置项 `fallbackToHostname` 为 `true`（默认），提取原 URL 的域名主机名（Hostname，例如 `github.com`、`b3log.org`）并经过第 3.3 节统一的空白/危险控制符净化与长度上限截断后作为降级标题回填；
  - 若 `fallbackToHostname` 为 `false`，则判定为提取失败，完全保留原 URL，不执行修改。

### 3.3 标题净化与长度截断
1. **HTML 实体解码**：将标题中的标准 HTML 实体与 Unicode 数字实体完整还原为对应字符；
2. **空白字符压缩**：将所有换行符（`\r`、`\n`）、制表符（`\t`）及多个连续半角空格统一压缩替换为单个半角空格；
3. **标题最大长度截断**：全部标题来源（网页标签、非网页文件名提取及域名降级回填）统一适用最大长度设置（默认 80 字素，范围 0~200，0 表示不限制）及危险方向/控制字符清洗（剥离双向控制符与 C0/C1 控制符并保留 `\u200C`/`\u200D`）；超过 3 字素且超出阈值时截取并追加 `...`，不大于 3 字素时直接按字素截断；
4. **无变化判定**：若净化后的最终标题与超链接当前的锚文本完全一致（且开启 `replaceTitle` 时悬浮标题属性亦一致），判定为无需写回，不提交事务。

## 4. 菜单动作与用户交互

### 4.1 单链接手动提取
- **入口**：在正文块内对 `http://` 或 `https://` 行内超链接点击右键（桌面端）或长按（移动端）弹出的链接上下文菜单（非 HTTP/HTTPS 协议如 `mailto:`、`siyuan://` 不展示该菜单项）；
- **行为**：绕过短期内存缓存发起强制联网请求并覆盖锚文本（无论当前链接是否已有自定义锚文本）；拉取失败降级为域名时，不将该降级域名写入短期内存缓存；
- **反馈**：耗时超过 1 秒时展示非模态提示；成功更新、标题已是最新、失败降级均有轻量状态反馈。

### 4.2 块级批量提取
- **入口**：在块图标菜单中，若当前块（或包含的子块）中存在 1 个及以上 `http://` / `https://` 行内超链接，挂载菜单项；
- **动态数量感应**：菜单标题实时计算并渲染链接数量，例如“批量提取链接标题 (共 3 个)”；
- **受控并发、在途去重与聚合回写**：最大并发网络请求数限制为 3；对同一块的重复并发批量触发实施在途去重门闩，避免重复点击叠加执行；批量提取不读写短期内存缓存（并发在途相同 URL 共享去重请求）；同块内所有链接拉取完成后，在单次事务中一并提交；
- **聚合单条通知**：全部链接处理完成后，发送单条聚合结果汇总。

## 5. 设置项结构与界面规范

设置保存在 `feature-titled-link-settings.json` 中（网络请求 User-Agent 统一复用 Core 平台全局设置，本特性不单设独立 User-Agent 选项）：
- **粘贴时自动提取链接标题**（`auto.enabled`）：默认开启；
- **同时替换悬浮标题属性 (`title`)**（`replaceTitle`）：默认关闭；
- **拉取失败时降级为网站域名**（`fallbackToHostname`）：默认开启；
- **标题最大长度**（`maxTitleLength`）：默认 80 字素（0 表示不限制）。
