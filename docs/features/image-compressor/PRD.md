## 1. 功能定位与产品边界

### 1.1 核心目标
OmniKit 图片压缩功能为思源笔记提供安全、透明、可追溯的图片 WebP 压缩与存储管理能力：
1. **非阻塞异步处理**：原生图片上传与编辑器插入立即完成，压缩任务在后台异步执行，不阻塞用户正常编辑；
2. **新增图片范围**：自动模式仅处理授权后新插入的图片，不静默扫描或修改文档存量图片；
3. **改写范围精确**：单图操作严格仅替换当前选中的单处引用（最小副作用原则），文档批量仅修改当前文档，不产生跨文档副作用；
4. **Dock 记录追溯**：生成的 WebP 统一由 Dock 进行持久化映射登记，支持路径复制与对称的双向引用管理（查找原图引用与恢复原图引用）；
5. **数据安全原则**：插件不主动删除任何原图或压缩图；写前基于精确节点比对，遇到并发修改安全放弃写回；业务记录持久化严格先于笔记引用更新；
6. **智能质量保护（MS-SSIM）**：为保障长期存储的图片画质与存储空间平衡，支持基于多尺度结构相似度（MS-SSIM）的自适应质量寻优。通过客观量化人眼视觉感知质量，在保证肉眼无损画质（默认相似度 $\ge 0.99$）的前提下自适应探索最优体积编码点，避免盲目使用固定低质量导致画质损伤或超高质量造成空间浪费，实现长期资产存储价值最大化。

### 1.2 功能边界 (Scope)

| 维度 | 纳入范围 (In-Scope) | 排除范围 (Out-of-Scope) |
|---|---|---|
| **图片检测** | 编辑器新插入（拖入/粘贴）图片的异步捕获；授权文档中的新增 HTTP/HTTPS 图片；统一路径与扩展名前置排除（常见视频、矢量、专有绘图） | 存量图片全库全量扫描；子文档递归继承授权 |
| **图片格式** | 静态 PNG、JPEG、WebP（支持二次优化）；标准 5 尺度 MS-SSIM 质量自适应评估 | 动态图片（GIF、APNG、动画 WebP）、矢量图（SVG）、常见视频、Excalidraw 绘图 |
| **触发方式** | 自动上传捕获、右键单图快捷压缩、右键单图弹窗微调（作用域仅限当前选中的单处引用）、当前文档批量压缩 | 笔记本全量扫描压缩、定时常驻扫描任务 |
| **文件管理** | 压缩 WebP 上传至思源 `assets`；原图始终保留 | 插件主动删除原图或 WebP 附件；自定义图片归档属性 |
| **引用改写** | 精确块级单图片位置改写（基于节点核验而非全局替换）；当前文档范围内按位置改写 | 跨文档全局重链接 (`relinkAsset`)；直接操作 `.sy` 文件或数据库 |
| **任务控制** | 系统生命周期中断保护（保留已完成产物、不回滚）；未授权完全静默与零开销（Silent by Default & Low Overhead）；用户按 Esc、切标签页时判定为正常中止并静默退出；状态栏进度展示 | 用户主动取消按钮；任务排队队列；失败自动重试机制 |
| **平台覆盖** | `desktop`（Win/Mac/Linux）、`browser-desktop`、`mobile`（App）、`browser-mobile`（手机浏览器） | - |

## 2. 自动新图压缩策略

### 2.1 异步处理时序
- **原生上传先行**：图片通过思源原生上传通道（拖拽、粘贴、上传按钮）直接上传至 `assets` 并插入编辑器。插件仅监听上传完成事件获取资源线索，不拦截原生上传，不阻塞编辑器输入；
- **异步定位与处理**：监听到上传完成事件后，等待思源内核完成块落盘，直接锁定持久化块中的精确图片位置，随后调度后台异步压缩；无死锁等待与额外轮询挂起；
- **编辑冲突保护**：异步处理期间用户可正常编辑。写前精确核验目标图片节点，若内容发生冲突，系统安全放弃替换当前引用，保留用户最新编辑内容。

### 2.2 自动压缩准入规则与未授权静默原则
- **彻底无感静默**：当新插入图片所在文档未开启自动压缩（全局自动压缩未开启且文档不在白名单中）时，系统完全静默处理，直接返回，不弹出任何气泡打扰用户编辑；
- **上传前纯同步授权与候选预筛选**：
  1. 授权判断为纯同步判定，仅在内存中读取当前配置、Feature 运行状态与白名单，无任何异步 I/O；
  2. 收到上传前事件时，同步基于输入文件类型判断是否包含可处理图片；未授权或不包含可处理候选图片时直接退出，不创建 DOM 观察器，不注册多余回调；
- **白名单规则**：
  - 白名单存储文档的唯一根 ID，不受文档改名或移动影响；
  - **白名单不继承**：仅对加入白名单的具体文档生效，子文档不继承父文档的白名单授权。

### 2.3 统一图片准入分类
- **常见视频扩展名统一前置排除**：`mp4, m4v, mov, avi, wmv, flv, mkv, webm, 3gp, ogv, mpeg, mpg, mts, m2ts, ts, vob, asf, rm, rmvb, f4v`；
- **Excalidraw 与专有绘图资产保护**：路径或文件名包含 `excalidraw`、或位于 `drawings/` / `drawing/` 专用目录的资源，统一识别为保护排除；
- **动图与矢量格式前置排除**：动态格式（`gif`, `apng`）与矢量格式（`svg`）直接跳过；
- **操作模式与 WebP 二次优化联动**：静态 WebP 图片在自动上传与文档批量模式下默认跳过，仅在手动弹窗微调模式下允许对 WebP 进行二次优化调整。

## 3. 远程外链图片处理规范

### 3.1 本地化前置与未授权设防原则
1. **未授权低开销设防**：若当前文档未获授权（未开启全局自动压缩且不在白名单中），不发起任何后台 DOM 查询与下载，直接短路退出；
2. **外链资源本地化**：通过思源接口将远程图片下载并上传为思源本地原图资产；
3. **引用更新模式分流**：
   - 自动上传压缩模式：该远程图片在笔记中的引用首先更新为思源本地原图路径，确保外链完成本地化；
   - 单图手动微调模式：遵循用户操作意图，若未勾选“是否使用压缩图替换当前图片”（`replace: false`），则严格不改写文档块内容，仅将原图与 WebP 上传至 assets 并写入业务记录；若勾选替换，则在 WebP 生成后将引用改写为 WebP 路径；
4. **加密笔记本资产支持**：支持携带 `?box=` 参数的加密笔记本资产 URL 规范解析与上传，引用写回均完整保留该参数。

### 3.2 远程下载网络规范
- **协议支持**：仅支持 `http://` 与 `https://` 协议；
- **请求配置**：单次下载超时为 30 秒，最大响应体体积限制为 32 MiB，自动跟随最多 3 次重定向；请求不附带思源身份凭证或 Cookie。

## 4. 格式、质量、尺寸与收益阈值

### 4.1 格式支持矩阵
| 图片格式 | 静态处理策略 | 动画/动态处理策略 | 说明 |
|---|---|---|---|
| **PNG** | 支持编码为 WebP | 不支持（检测到 APNG 时跳过） | 完整保留透明通道（Alpha） |
| **JPEG / JPG** | 支持编码为 WebP | 无 | 纠正 EXIF 旋转方向 |
| **WebP** | 支持二次重编码优化（满足阈值时） | 不支持（多帧动图 WebP 跳过） | 保护多帧动画 WebP 不被转换为单帧静态图 |
| **GIF** | 跳过 | 跳过 | 不转码，保留动图播放 |
| **SVG** | 跳过 | 跳过 | 矢量图不转码，保持矢量缩放 |
| **Excalidraw 绘图** | 跳过 | 跳过 | 专有绘图资产受固定保护 |

### 4.2 收益阈值 (Compression Thresholds)
编码后的 WebP 需同时满足以下条件才进行替换：
1. **体积下限**：输入原图 $\ge 100\text{ KiB}$ ($102,400\text{ 字节}$)，小于 100 KiB 跳过；
2. **绝对节省**：压缩产物比原图节省 $\ge 4\text{ KiB}$ ($4,096\text{ 字节}$)；
3. **相对节省**：体积节省比例 $\ge 5\%$ ($0.05$)。

> 未达到上述任一阈值时跳过替换，保持原图引用。

### 4.3 尺寸保护规范
- **自动模式保持原尺寸**：在自动上传压缩与文档批量压缩中，输出 WebP 保持与输入原图相同的像素宽高（`keepResolution: true`）；
- **手动模式等比缩放**：仅在手动操作中，若配置了“手动最大边长”（默认 4096 px），图片长边超过该阈值时等比缩小，保持宽高比，不进行非等比拉伸或裁切。

### 4.4 智能压缩质量规格 (Adaptive MS-SSIM)
1. **保留高保真画质**：采用标准 5 尺度多尺度结构相似度（MS-SSIM）算法，对含透明通道图片执行 Alpha 预乘处理，杜绝边缘杂色干扰；
2. **目标相似度控制**：默认目标相似度为 0.99（即 99% MS-SSIM，属于肉眼无损级别）；
3. **达标体积最优**：在达到目标相似度的合格质量区间内，选取文件体积最小的 WebP 作为最终产物；若最高质量（1.00）仍无法达到目标相似度，算法判定为未达标并放弃替换，严格保护图片质量。

## 5. 菜单动作与用户交互

### 5.1 单图操作：压缩此图片
- **入口**：编辑器图片右键菜单；
- **行为**：使用默认压缩质量与阈值在后台执行压缩与上传；
- **作用域**：严格限定为仅替换当前选中的单处引用；同块内其他图片或同文档其他位置保持不变；
- **反馈**：无弹窗打扰，完成后发送轻量状态提示。

### 5.2 单图操作：压缩…（弹窗微调）
- **入口**：编辑器图片右键菜单；
- **界面交互**：
  - 原图与 WebP 压缩图并列对比卡片布局，直观展示两端图片缩略图、像素尺寸、格式及体积；
  - 提供体积节省徽章，显示节省字节与节省百分比；
  - 滑块带实时数值气泡，可调节 WebP 压缩质量与手动最大边长；
  - 提供“是否使用压缩图替换当前图片”复选框，默认未勾选（仅保存不替换）；
  - 勾选替换并确认时，替换当前选中引用的图片；未勾选时仅保存 WebP 至记录库，严格不改写文档正文。

### 5.3 文档批量：压缩当前文档图片
- **入口**：文档树节点右键菜单、编辑器标题区域右键菜单；
- **行为**：
  - 扫描当前文档中所有合规图片块（含折叠块），通过只读查询单次批量获取图片信息，避免反复往返；
  - 任务明确划分“准备资源”与“应用替换”两个阶段，居中进度面板实时汇报进度与当前文件名；
  - 扫描结果为 0 时，自动关闭进度面板并提示“当前文档未发现可压缩图片”；
  - 批量任务执行期间用户关闭面板或按 Esc，判定为正常中止，静默安全退出。

### 5.4 白名单快捷菜单
- 文档右键菜单与文档树菜单根据当前文档是否在白名单中动态计算文案与状态：
  - 未在白名单中：展示“开启当前文档图片自动压缩”；
  - 已在白名单中：展示“关闭当前文档图片自动压缩”。

## 6. 原图记录 Dock 面板与数据管理

1. **记录追溯能力**：
   - 生成的 WebP 映射统一登记至专属 Tab 面板（标题：“图片压缩记录”）；
   - 列表按操作时间倒序直观呈现最新结果，展示原图路径、WebP 路径、操作时间与模式；
   - 提供便捷复制 WebP 路径及查找原图引用的交互按钮；
2. **数据安全与隔离**：
   - 业务记录独立保存在 `feature-image-compressor-records.json` 中；
   - 设置重置或清理设置时绝对不影响业务记录数据文件；
   - 记录的清空必须在专区由用户显式确认后方可执行。

## 7. 后续演进与能力提升 (Future Enhancements)

1. **AVIF / JXL 现代编码格式扩展**：在思源内核与前端引擎支持成熟时，探索更高效的静态图片编码格式；
2. **多文档批量并行压缩**：支持跨多个文档或整个笔记本目录的批量计划与执行管理；
3. **已压缩图片历史快照比对**：与思源文档历史版本联动，提供图片历史压缩演进的可视化对比。
