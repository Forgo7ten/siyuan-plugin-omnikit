## 1. 功能定位与产品边界

### 1.1 核心目标
OmniKit 图片压缩功能为思源笔记提供安全、透明、可追溯的图片 WebP 压缩与存储管理能力：
1. **非阻塞异步处理**：原生图片上传与编辑器插入立即完成，压缩任务在后台异步执行，不阻塞用户正常编辑；
2. **新增图片范围**：自动模式仅处理授权后新插入的图片，不静默扫描或修改文档存量图片；
3. **改写范围精确**：单图操作严格仅改写当前选中的单处引用（最小副作用原则），文档批量仅修改当前文档，不产生跨文档副作用；
4. **Dock 记录追溯与双向引用管理**：生成的 WebP 统一由 Dock 进行持久化配对登记（`原图 → 最新 WebP`），支持路径复制与对称的双向引用管理（查找原图引用含图片与普通资源链接，并支持单处精确替换与恢复）；
5. **数据安全原则**：插件不主动删除任何物理原图或压缩图；写前基于精确位置核验，遇到并发修改安全放弃写回；业务记录持久化严格先于笔记引用更新；仅当某条记录的原图或最新压缩图经权威可信证据确认为物理缺失时，自动移除该单条失效业务记录，缺乏可靠缺失证据时完整保留；
6. **固定质量与智能质量并存**：支持固定质量编码与可选的多尺度结构相似度（MS-SSIM）自适应质量寻优并存；在启用智能模式时，通过客观量化人眼视觉感知质量，在满足肉眼无损阈值（默认相似度 $\ge 0.99$）的前提下自适应探索最优体积编码点，兼顾画质保护与长期存储空间效率。

### 1.2 功能边界 (Scope)

| 维度 | 纳入范围 (In-Scope) | 排除范围 (Out-of-Scope) |
|---|---|---|
| **图片检测** | 编辑器新插入（拖入/粘贴）图片的异步捕获；授权文档中的新增 HTTP/HTTPS 图片；统一路径与扩展名前置排除（常见视频、矢量、专有绘图） | 存量图片全库全量扫描；子文档递归继承授权；既有图片属性编辑误认 |

| **引用改写** | 精确块级单图片或单普通资源链接位置改写（基于节点核验而非全局替换）；当前文档范围内按位置改写；`?box=` 加密笔记本按授权笔记本范围接口查找 | 跨文档全局重链接；直接操作 `.sy` 文件或数据库；对属性视图/数据库等无法映射为单块可编辑节点的引用执行自动改写 |
| **任务控制** | 插件运行期间切换文档或关闭编辑器不中止已启动后台任务；用户主动关闭批量进度弹窗（含按 Esc）中止本批次尚未开始步骤；程序主动关闭完成/失败面板仅关闭界面，不记为用户取消；Feature 停用、插件卸载或宿主退出中止未开始步骤，保留已确认产物与记录，不回滚、重启不续跑；展示两阶段进度与独立 `未知 (unknown)` 统计 | 独立取消按钮、取消菜单或公开取消 API；任务排队队列；失败自动重试机制；状态未知写操作的盲目重发 |
| **平台覆盖** | `desktop`（Win/Mac/Linux）、`desktop-window`、`browser-desktop`、`mobile`（App）、`browser-mobile`（手机浏览器） | - |

## 2. 自动新图压缩策略

### 2.1 异步处理时序
- **原生上传先行**：图片通过思源原生上传通道（拖拽、粘贴、上传按钮）直接上传至 `assets` 并插入编辑器。插件仅监听上传事件并采纳本次上传对应的新增节点证据，不拦截原生上传，不阻塞编辑器输入；当上传因资源复用等原因未能产生可唯一识别的新增节点证据时，安全跳过处理，不扫描或改写既有存量图片；
- **异步定位与处理**：监听到上传完成事件后，等待思源内核完成块落盘并锁定持久化块中的精确图片位置，随后调度后台异步压缩；
- **编辑冲突保护**：异步处理期间用户可正常编辑。写前精确核验目标图片节点，若内容发生冲突，系统安全放弃替换当前引用，保留用户最新编辑内容。

### 2.2 自动压缩准入规则与未授权静默原则
- **彻底无感静默**：当新插入图片所在文档未开启自动压缩（全局自动压缩未开启且文档不在白名单中）时，系统完全静默处理，直接返回，不弹出任何气泡打扰用户编辑；
- **上传前纯同步授权与候选预筛选**：
  1. 授权判断为纯同步判定，仅在内存中读取当前配置、Feature 运行状态与白名单，无任何异步 I/O；
  2. 收到上传前事件时，同步基于输入文件类型判断是否包含可处理图片；未授权或不包含可处理候选图片时直接退出，不创建 DOM 观察器，不注册多余回调；
- **白名单规则**：
  - 白名单存储文档的唯一根 ID，不受文档改名或移动影响；
  - **白名单不继承**：仅对加入白名单的具体文档生效，子文档不继承父文档的白名单授权。

### 2.3 统一图片准入分类
- **常见视频扩展名统一前置排除**：`mp4, m4v, mov, avi, wmv, flv, mkv, webm, 3gp, ogv, mpeg, mpg, mts, m2ts, ts, vob, asf, rm, rmvb, f4v`；
- **Excalidraw 与专有绘图资产保护**：路径或文件名包含 `excalidraw`、或位于 `drawing/` / `drawings/` 专用目录的资源，统一识别为保护排除；普通文件名（如 `drawings_v2.png`、`drawing-foo.png`）正常参与准入判定；
- **动图与矢量格式前置排除**：动态格式（`gif`、`apng`、多帧动画 `webp`）与矢量格式（`svg`）在所有操作模式下均直接跳过；
- **静态 WebP 准入模式分流**：
  - 自动上传与当前文档批量压缩模式跳过静态 WebP；
  - 右键快捷压缩（「压缩此图片」）与右键弹窗微调（「压缩…」）模式均允许对静态 WebP 进行再编码优化，其中右键快捷压缩仍遵守体积与节省收益阈值，右键弹窗支持在用户显式确认后保存。

## 3. 远程外链图片处理规范

### 3.1 本地化前置、未授权设防与手动远程保存语义
1. **未授权低开销设防**：若当前文档未获授权（未开启全局自动压缩且不在白名单中），不发起任何后台 DOM 查询与下载，直接短路退出；
2. **外链资源单处本地化**：在授权自动场景或手动单图确认保存时，通过流式下载获取远程图片并上传为思源本地原图资产，且仅改写当前选中的单处引用位置，不影响同文档其他远程图片；
3. **引用更新模式分流**：
   - **自动上传压缩模式**：该远程图片在笔记中的当前位置引用先更新为思源本地原图路径完成本地化，在 WebP 编码达标、上传并持久化 Dock 配对记录后替换为 WebP 路径；
   - **手动微调模式（远程图片）**：预览阶段保持完全只读（不上传资源，不改写文档）；用户确认保存时：
     - **不勾选“保存后替换当前图片”（仅保存 WebP）**：系统仍先将当前选中的这一处远程图片本地化为思源本地原图并更新该处引用，同时上传压缩 WebP 至 `assets/` 并写入 Dock 配对记录（`本地原图 → WebP`），使当前位置保持引用本地原图而不替换为 WebP；
     - **勾选“保存后替换当前图片”**：先将该处远程图片本地化为本地原图，并在重读核验更新后的块状态后，再上传 WebP、持久化 Dock 配对记录并将该单处引用改写为 WebP 路径；
     - **容错边界**：若远程原图本地化已成功但后续 WebP 上传或记录持久化失败，已本地化的原图资产与当前引用保留不变（不回滚）；若远程下载或原图本地化失败，保持原远程链接不变并中止后续步骤；
   - **手动微调模式（已有本地 `assets/` 图片）**：不勾选“保存后替换当前图片”时仅上传 WebP 并持久化 Dock 记录，完全不改写文档正文；勾选替换时在上传并持久化记录后将当前单处引用改写为 WebP 路径；
4. **加密笔记本与展示参数支持**：支持携带 `?box=<notebookID>` 参数的加密笔记本资产路径解析、上传与保留写回，同时兼容并区分仅作展示用途的查询参数或片段（如 `?width=`、`#fragment`）与资源物理身份。

### 3.2 远程下载网络规范
- **协议支持**：仅支持 `http://` 与 `https://` 协议；
- **请求限制与校验**：单次下载总超时为 30 秒，最大响应体流式读取上限为 32 MiB；请求不附带思源身份凭证或 Cookie，并执行图片格式与 XSS 内容校验；
- **重定向与宿主原生语义对齐**：远程图片下载参照思源原生“网络图片转本地”的网络请求行为，跟随平台/宿主允许的合法 HTTP 重定向，不设固定 3 跳拦截及额外私网 IP/DNS 拦截；桌面端复用 Core 平台统一的 `User-Agent` 配置；
- **已接受的网络安全边界**：因下载通道遵循宿主原生语义而未额外拦截内网/回环/链路本地地址，当笔记中存在不受信任的外部 URL 时，与思源原生外链本地化具有同等的 SSRF 访问风险边界。

## 4. 格式、质量、尺寸与收益阈值

### 4.1 格式支持矩阵
| 图片格式 | 静态处理策略 | 动画/动态处理策略 | 说明 |
|---|---|---|---|
| **PNG** | 全模式支持编码为 WebP | 不支持（检测到 APNG 时跳过） | 完整保留透明通道（Alpha） |
| **JPEG / JPG** | 全模式支持编码为 WebP | 无 | 纠正 EXIF 旋转方向；不保留 EXIF 元数据 |
| **WebP** | 自动与批量模式跳过；右键快捷压缩与右键弹窗支持重编码 | 不支持（多帧动图 WebP 全模式跳过） | 保护多帧动画 WebP；右键重编码生成新的独立 `原图 → 新 WebP` 配对记录，不构建链式版本历史 |
| **GIF** | 跳过 | 跳过 | 不转码，保留动图播放 |
| **SVG** | 跳过 | 跳过 | 矢量图不转码，保持矢量缩放 |
| **Excalidraw 与专有绘图目录** | 跳过 | 跳过 | `excalidraw` 资产及 `drawing/`、`drawings/` 目录资产受保护，不误排除普通文件名 |

### 4.2 收益阈值与例外规则
1. **自动、文档批量与右键快捷压缩门槛**：编码后的 WebP 需同时满足以下条件才进行上传与替换：
   - **体积下限**：输入原图 $\ge 100\text{ KiB}$ ($102,400\text{ 字节}$)，小于 100 KiB 跳过；
   - **绝对节省**：压缩产物比原图节省 $\ge 4\text{ KiB}$ ($4,096\text{ 字节}$)；
   - **相对节省**：体积节省比例 $\ge 5\%$ ($0.05$)。
   > 未达到上述任一阈值时跳过替换，保持原图引用。
2. **手动弹窗微调例外**：在右键「压缩…」弹窗中，用户可对小于 100 KiB 或未达到收益阈值的静态合规图片进行预览，并在显式点击保存后上传与记录（若压缩产物大于原图，须经用户额外确认后方可执行保存）。

### 4.3 尺寸保护规范
- **自动模式保持原尺寸**：在自动上传压缩与文档批量压缩中，输出 WebP 保持与输入原图相同的像素宽高；
- **手动模式等比缩放**：仅在手动操作中，若配置了“手动压缩最大边长”（默认 4096 px），图片长边超过该阈值时等比缩小，保持宽高比，不进行非等比拉伸或裁切。

### 4.4 质量模式规格（固定质量与智能画质并存）
系统同时支持**固定质量模式**与**可选 MS-SSIM 智能画质模式**，两者互斥按配置调度：
1. **固定质量模式（默认模式）**：智能模式默认关闭；编码直接使用配置的初始质量值（默认 `0.80`）生成 WebP 产物；
2. **可选 MS-SSIM 智能画质模式**：
   - 用户可在设置中开启智能画质模式；启用后以配置质量作为初始搜索起点，不保证最终产物质量等于该初始值；
   - 采用标准 5 尺度多尺度结构相似度（MS-SSIM）算法，对含透明通道图片执行 Alpha 预乘处理，杜绝边缘杂色干扰；
   - **目标相似度控制**：默认目标相似度为 0.99（即 99% MS-SSIM，属于肉眼无损级别）；
   - **达标体积最优**：在达到目标相似度的合格质量区间内，选取文件体积最小的 WebP 作为最终产物；若最高质量（1.00）仍无法达到目标相似度，算法判定为未达标并放弃替换，严格保护图片质量。

## 5. 菜单动作与用户交互

### 5.1 单图操作：压缩此图片
- **入口**：编辑器图片右键菜单；
- **行为**：使用当前配置的质量模式与收益阈值在后台执行压缩与上传（支持静态 PNG、JPEG 与静态 WebP）；
- **作用域**：严格限定为仅替换当前选中的单处引用；同块内其他图片或同文档其他位置保持不变；
- **反馈**：无弹窗打扰，完成后发送轻量状态提示。

### 5.2 单图操作：压缩…（弹窗微调）
- **入口**：编辑器图片右键菜单；
- **界面交互**：
  - 原图与 WebP 压缩图并列对比卡片布局，直观展示两端图片缩略图、像素尺寸、格式及体积；
  - 提供体积节省徽章，显示节省字节与节省百分比；
  - 滑块带实时数值气泡，可调节 WebP 压缩质量与手动最大边长；
  - 提供“保存后替换当前图片”复选框，默认未勾选（仅保存 WebP 产物）；若压缩产物大于原图，保存前弹出额外确认；
  - 界面层不展示 EXIF 保留选项控件；配置数据中的 `metadata.preserveExif` 作为内部保留字段保持默认 `false`；
  - 勾选替换并确认时，替换当前选中引用的图片（若为远程图片，先完成单处本地化再替换）；未勾选时对已有本地 `assets/` 图片仅保存 WebP 至记录库且不改写文档正文，对远程图片则先将当前选中位置本地化为思源本地原图并同步将 WebP 写入记录库。

### 5.3 文档批量：压缩当前文档全部图片
- **入口**：文档树节点右键菜单、编辑器标题区域右键菜单、顶栏菜单；
- **行为**：
  - 扫描当前文档中所有合规图片块（含折叠块），通过单次文档结构读取定位图片位置（跳过静态 WebP 与动图/矢量/专有绘图）；
  - 进度弹窗呈现“准备资源”与“应用替换”两个阶段，实时汇报当前进度与文件名；弹窗不设独立“取消”按钮；
  - 任务启动后，切换当前文档标签页或关闭编辑器不影响后台批量任务继续执行；
  - 用户主动关闭批量进度弹窗（含按 Esc 或点击弹窗关闭按钮）时，中止本批次尚未开始的后续步骤（保留已确认上传产物、记录与已提交块改写，不执行回滚，不续跑）；
  - 扫描结果为 0 且扫描正常完成时，程序主动关闭进度弹窗并提示“当前文档没有可处理的图片。”；文档扫描失败时程序主动关闭弹窗并提示“文档扫描失败，未开始压缩。”；上述程序主动关闭UI的行为不计为用户取消；
  - 批量任务结束时发送单条聚合汇总通知，独立统计并展示处理结果（含已替换/成功、跳过、冲突、失败及独立 `未知 (unknown)` 计数，不将中止或状态未知项计为失败）。

### 5.4 白名单快捷菜单
- 文档右键菜单与文档树菜单根据当前文档是否在白名单中动态计算文案与状态：
  - 未在白名单中：展示“开启当前文档图片自动压缩”；
  - 已在白名单中：展示“关闭当前文档图片自动压缩”。

## 6. 原图记录 Dock 面板与数据管理

1. **记录追溯与状态核验能力**：
   - 生成的 WebP 配对映射统一登记至专属 Tab 面板（标题：“图片压缩记录”）；
   - 列表按最新操作时间倒序呈现结果（更新既有映射或执行操作后按最新时间置顶），展示原图路径、WebP 路径、操作时间、最近操作与资产存在性状态徽章（`存在` / `确认不存在` / `未知`）；
   - 按需同步尚未下载但已被内核登记的逻辑文件在状态核验中视作 `存在`；
   - 提供便捷复制资源路径、查找原图引用、恢复原图（仅原图状态为 `存在` 时可用）及手动移除记录按钮；
2. **引用查找与单处精确改写范围**：
   - 引用查找同时覆盖图片位置与普通资源链接位置，并按类型（图片引用、普通资源链接、不支持自动改写位置）分组展示，支持点击跳转至对应文档位置；
   - 用户选定单处引用或批量执行替换/恢复时，仅精确改写对应图片的引用目标或对应普通资源链接的目标路径，保持同块内其他图片、链接与文字内容完整不变；
   - 对属性视图/数据库等宿主可发现但无法映射为单块可编辑节点的引用，仅作只读展示或提示“该位置暂不支持自动改写”，不调用跨文档全局重链接；
   - 携带 `?box=<notebookID>` 的加密笔记本资产仅在对应笔记本已解锁且获授权的范围内通过专用接口执行查找与改写，不以忽略查询参数的全局查找替代；当加密笔记本处于锁定或无权限状态时，查找与恢复报告为不可用或 `未知`，不误判为“没有引用”或“文件缺失”；
3. **配对记录自动清理与数据安全边界**：
   - 业务记录独立保存在 `feature-image-compressor-records.json` 中；
   - **失效配对单条自动移除**：在 Dock 打开/激活、用户手动刷新或压缩后写入记录时，对单条配对记录独立核查原图与**最新**压缩 WebP 的存在性（无后台定时轮询或跨会话持久化状态缓存；当前 Dock 会话对切 tab 触发的核验保留 10 分钟内存 TTL 缓存以防重复探测并排除 `未知`，用户手动刷新强制重查）；当且仅当该条记录的原图或最新 WebP 经权威、可证明物理不存在的证据确认为缺失时，自动移除该一条失效业务记录；
   - **安全隔离约束**：自动清理仅移除业务记录文件中的该单条配对条目，绝不删除 `assets/` 中的任何物理文件，绝不依据一条记录缺失而对其他链条记录（如 `A → B` 与 `B → C`）执行级联删除；
   - **确认不存在的技术判别约束**：当后端接口返回不区分“文件物理不存在”与“路径解析失败/权限错误/锁定/同步未就绪/I/O 故障”的含混错误码，或发生网络/超时异常时，资产状态标记为 `未知 (unknown)` 并完整保留对应业务记录；严禁凭猜测、无引用结果或重复同一含混请求强行删除记录；
   - **容量与持久化边界**：设置重置不影响业务记录文件；记录库设 10,000 条记录的轻量容错上限，达到上限时完整保留既有全部记录、支持已有映射原地更新、拒绝继续新增；若写入持久化文件发生失败（含触达上限），持久化前置闸门阻断后续自动引用替换并向用户暴露可复制的新资源路径；在插件设置窗口集中查看与清空全部业务数据的能力纳入平台“数据管理”专区规划（见 [CORE-PRD.md](../../CORE-PRD.md) 第 9 节）。
