## 1. 功能定位与产品边界

### 1.1 核心目标
OmniKit 图片压缩功能可将图片编码为 WebP，并管理原图与压缩图的对应记录：
1. 图片上传和插入完成后，压缩在后台进行，不影响用户继续编辑；
2. 自动压缩只处理已开启自动压缩的文档中新插入的图片，不扫描或修改文档中已有的图片；
3. 单图操作只更新用户选中的图片引用；文档批量操作只更新包含目标图片的块，不提交未修改的块或整篇文档；
4. Dock 保存本地压缩配对记录（`原图 → 最新 WebP`）以及远程图片下载本地化配对记录（`图片链接 → 本地原图`），提供路径复制、双向查找图片和资源链接引用、替换与恢复功能；
5. 插件不删除原图或压缩图文件。更新文档前会核验目标块归属及目标图片/链接节点；发现块已迁移或目标位置引用已变化时跳过更新，写回时仅基于实时块内容修改目标节点，不覆盖同块其他内容。将远程图片替换为本地原图以及将本地原图替换为 WebP 前，均先保存对应记录。远程图片先保存到思源并更新为本地原图引用。普通 `原图 → 最新 WebP` 记录在确认原图或最新 WebP 任一不存在时自动移除；外链 `图片链接 → 本地原图` 记录仅检查本地原图是否存在，在确认本地原图不存在时自动移除（保留本地原图时由用户手动移除）；无法确认时保留记录；
6. 支持固定质量编码和可选的“智能压缩 (MS-SSIM)”设置。开启该设置后，默认相似度目标为 0.99，并从达到目标的结果中选择文件较小的 WebP。

### 1.2 功能范围

| 维度 | 包含 | 不包含 |
|---|---|---|
| **图片检测** | 编辑器中新插入（拖入或粘贴）的图片；已开启自动压缩的文档中新增的 HTTP/HTTPS 图片；用户主动启动的当前文档批量操作中的远程图片；按路径和扩展名跳过视频、矢量图及专有绘图文件 | 扫描全部文档中的已有图片；子文档继承父文档的白名单设置；将已有图片属性修改识别为新图片 |
| **图片格式** | 静态 PNG、JPEG（所有操作模式均支持）；静态 WebP（右键快捷压缩与右键“压缩…”支持；自动上传与文档批量仅在开启“智能压缩 (MS-SSIM)”时支持）；标准 5 尺度 MS-SSIM 图片质量比较 | 动态图片（GIF、APNG、动画 WebP）、矢量图（SVG）、常见视频、Excalidraw 及专有绘图目录中的文件 |
| **触发方式** | 图片上传后自动压缩、右键“压缩此图片”、右键“压缩…”、批量压缩当前文档 | 扫描所有笔记本中的图片；定时扫描图片 |
| **文件管理** | 压缩后的 WebP 上传至思源 `assets`；插件不删除原图或压缩图文件；确认原图或最新 WebP 不存在时，自动移除对应的 Dock 记录 | 删除原图或 WebP 文件；自定义图片归档属性；删除其他记录中引用该文件的配对 |
| **引用更新** | 只更新对应图片或普通资源链接的目标路径；批量操作只更新当前文档；只在已解锁且有权限的加密笔记本中查找 | 跨文档批量更新；直接读写 `.sy` 文档文件或数据库；自动更新属性视图、数据库等无法定位到具体编辑块的引用 |
| **任务控制** | 切换文档或关闭编辑器后，已开始的后台任务继续运行；批量操作逐块等待编辑保存并重新查找目标图片；关闭批量进度窗口时停止尚未开始的步骤；插件停用、卸载或宿主退出时停止尚未开始的步骤，已完成的文件和记录保留，重启后不继续任务；进度分别显示资源准备和引用更新，并单独统计结果未知的项目 | 单独的取消按钮或菜单；向用户展示或保存待处理任务列表；失败后自动重试；结果不确定时自动重复写入 |
| **平台覆盖** | 桌面版（Windows、Mac、Linux）、桌面窗口版、桌面浏览器、移动应用、手机浏览器 | - |

## 2. 自动新图压缩策略

### 2.1 自动处理过程
- 图片通过思源的拖拽、粘贴或上传按钮上传到 `assets` 并插入编辑器。插件不拦截上传，也不影响编辑；
- 图片插入后，插件等待思源保存对应内容，再定位本次新增的图片并在后台压缩。如果无法确认哪张图片是本次新增的，插件跳过处理，不查找或修改文档中已有的图片；
- 压缩完成后，插件更新图片引用前会再次检查目标图片。如果图片已被修改或删除，插件跳过更新并保留用户当前内容；
- 单张新图（含本地上传与远程外链新增图片）自动压缩完成并替换引用后，发送轻量状态提示，展示原体积、现体积与带符号体积变化比例（如“图片压缩成功：原体积 → 现体积（-75.0%）”）；同批多张图片处理完成时，发送简要分项汇总提示；
- 每项图片压缩任务（包含成功保存、跳过与失败状态，以及文档批量的逐处引用更新状态）均通过控制台 `info` 日志输出结构化诊断信息，涵盖原图路径、压缩图路径（如有）、前后体积与体积变化比例（如有）；开启智能压缩（MS-SSIM）时额外记录目标相似度、质量、实测相似度与搜索轮次，不向工作区写入日志文件。

### 2.2 自动压缩的启用条件
- 当新图片所在文档未开启自动压缩（全局自动压缩未开启，且该文档不在白名单中）时，不处理该图片，也不显示提示；
- 图片上传前，插件会检查自动压缩是否已开启以及上传内容是否包含支持的图片。未开启或没有支持的图片时，不继续监听这次上传；
- **白名单规则**：
  - 白名单仅持久化存储文档的唯一根 ID 与授权时间戳（不保存文档标题或路径字段），不受文档改名或移动影响；
  - 设置面板展示白名单列表时，通过单条只读 SQL 批量查询文档所属笔记本与层级路径并配合笔记本列表实时拼接完整路径（对未入库或未解锁加密笔记本中的文档按需回退单文档路径查询或显示根 ID），浏览设置页时不触发配置文件写入；
  - **白名单不继承**：仅对加入白名单的具体文档生效，子文档不继承父文档的白名单授权。

### 2.3 支持处理的图片类型
- 以下常见视频格式始终跳过：`mp4, m4v, mov, avi, wmv, flv, mkv, webm, 3gp, ogv, mpeg, mpg, mts, m2ts, ts, vob, asf, rm, rmvb, f4v`；
- 路径或文件名包含 `excalidraw`，或位于 `drawing/`、`drawings/` 目录中的绘图文件始终跳过。普通文件名（如 `drawings_v2.png`、`drawing-foo.png`）仍可处理；
- 动图格式（`gif`、`apng`、多帧动画 `webp`）和矢量格式（`svg`）始终跳过；当前自动与批量远程识别先按路径扩展名过滤，无扩展名的远程动图或矢量图在下载后可能先完成本地化保存，随后在压缩阶段因格式不受支持而跳过或失败；
- 静态 WebP 的处理方式：
  - 自动上传与当前文档批量压缩根据“智能压缩 (MS-SSIM)”设置处理静态 WebP：关闭时跳过，开启时处理；
  - 右键“压缩此图片”和“压缩…”均可重新编码静态 WebP。快捷压缩仍需达到文件大小和节省量要求；在“压缩…”弹窗中点击“保存 WebP 到思源”即开始保存。若 WebP 大于原图，须先勾选相应复选框才能保存。

## 3. 远程图片处理

### 3.1 远程图片的本地保存与手动操作
1. **自动处理的启用条件**：插件只在当前文档已开启自动压缩时检查和下载远程图片。用户主动启动当前文档批量压缩或在单图弹窗中点击“保存 WebP 到思源”时，按手动操作规则处理，不受自动压缩开关影响；
2. **将远程图片保存到思源**：自动压缩、用户启动的文档批量压缩或用户点击“保存 WebP 到思源”时，插件下载远程图片并上传到思源 `assets`。批量处理时，相同 URL 只下载并上传一次；每处图片引用仍分别检查和更新；
3. **不同操作下的图片引用更新方式**：
   - **自动上传压缩**：先下载上传远程图片并在 Dock 保存 `图片链接 → 本地原图` 记录，再将笔记中的远程图片引用更新为思源本地原图路径。WebP 编码达到要求、上传成功且 Dock 保存 `本地原图 → WebP` 记录后，再将该处引用更新为 WebP 路径；
   - **手动微调模式（远程图片）**：预览阶段不上传图片或修改文档；用户点击“保存 WebP 到思源”后：
     - **不勾选“保存后替换当前图片”（仅保存 WebP）**：先将当前选中的远程图片保存到思源、在 Dock 保存 `图片链接 → 本地原图` 记录并将该处引用改为本地原图路径；再上传 WebP 并在 Dock 保存 `本地原图 → WebP` 记录。文档继续引用本地原图；
     - **勾选“保存后替换当前图片”**：先将该处远程图片保存到思源、在 Dock 保存 `图片链接 → 本地原图` 记录并更新引用，再检查文档中的最新内容；之后上传 WebP、在 Dock 保存 `本地原图 → WebP` 记录，并将该处引用改为 WebP 路径；
     - **失败时的处理**：远程图片已保存到思源，但之后上传 WebP 或保存 Dock 记录失败时，保留本地原图及当前引用。下载远程图片或上传本地原图失败时，保留远程链接并停止后续处理；
   - **手动微调模式（已有本地 `assets/` 图片）**：不勾选“保存后替换当前图片”时，只上传 WebP 并在 Dock 保存记录，不修改文档；勾选替换时，上传 WebP 并保存记录后，将当前图片引用改为 WebP 路径；
4. **加密笔记本与参数处理规则**：
   - 支持处理带有 `?box=<notebookID>` 参数的加密笔记本图片路径，并保留该参数；
   - **远程图片本地化**：将远程 URL 本地化为思源 `assets/` 附件时，仅保留新上传生成的 `?box=<notebookID>`，丢弃源远程 URL 的所有查询参数与片段（如 `token`、签名或远程片段），避免将远端鉴权或第三方服务参数写入本地链接；
   - **已有本地附件引用替换**：替换为新的本地附件路径（如压缩为 WebP 或恢复原图）时，仅保留新产物的 `?box=<notebookID>` 与原有的片段（`#fragment`），丢弃其他查询参数（思源图片缩放通过外层 DOM `style` 属性维护）。

### 3.2 文档批量处理远程图片
1. **相同 URL 只下载一次**：当前文档中 URL 相同的远程图片共用一次下载和一份上传到思源的原图。每处引用仍分别检查和更新，不会因为 URL 相同而一次改动多个位置。
2. **先保存记录并更新引用，再压缩**：下载并上传远程图片到思源后，在 Dock 保存 `图片链接 → 本地原图` 记录，并将文档中的远程引用逐一更新为该思源本地原图路径；随后压缩这份原图、上传 WebP 并在 Dock 保存 `本地原图 → WebP` 记录。一次远程图片完整压缩会产生 `图片链接 → 本地原图` 与 `本地原图 → WebP` 两条独立记录（例如：`https://example.com/photo.png → assets/photo-xxxx.png` 与 `assets/photo-xxxx.png → assets/photo-xxxx.webp`）。
3. **失败后的文件和引用状态**：
   - 远程下载或本地原图上传失败：该 URL 组的引用保持远程状态；
   - 原图已上传，但某处引用更新失败：该处仍使用远程地址，上传的原图可能没有文档引用；
   - 图片已保存到思源，但 WebP 压缩失败：文档继续引用本地原图；
   - WebP 上传或 Dock 保存记录失败：文档继续引用本地原图，不改为 WebP；
   - WebP 引用替换发生冲突：保留用户最新编辑内容，不覆盖该引用。
4. **失败后保留已完成的内容**：后续步骤失败时，不撤销已完成的引用更新、已上传文件或已保存记录。插件不自动删除没有引用的原图或 WebP 文件。

### 3.3 自动处理远程图片的数量限制
- 自动处理期间，插件会在内存中暂存尚未处理的图片地址。列表不会显示给用户，也不会保存；插件停用、卸载或退出后，不会继续处理剩余图片。
- 移动端并发数为 1；桌面端默认并发数为 3。每批最多处理 20 张，完成后继续处理下一批，直到本轮图片处理完毕。
- 单张图片处理失败后记录失败并继续处理其他图片，不自动重试。插件停用、卸载或宿主退出时，停止尚未开始的处理。

### 3.4 远程下载网络规范
- **协议支持**：仅支持 `http://` 与 `https://` 协议；
- **请求限制与校验**：单次下载总超时为 30 秒，最大响应体流式读取上限为 32 MiB；请求不附带思源身份凭证或 Cookie，并执行图片格式与 XSS 内容校验；
- **重定向**：下载行为遵循思源“网络图片转本地”的规则，可跟随宿主允许的 HTTP 重定向；不限制为 3 次，也不额外拦截内网、本机或链路本地地址。桌面端使用插件通用设置中提供的 `User-Agent`；
- **网络访问范围**：由于插件遵循思源的下载规则，笔记中的外部图片地址可能指向内网或本机服务，其网络访问范围与思源“网络图片转本地”功能相同。

## 4. 图片格式、质量和尺寸要求

### 4.1 格式支持矩阵
| 图片格式 | 静态处理策略 | 动画/动态处理策略 | 说明 |
|---|---|---|---|
| **PNG** | 全模式支持编码为 WebP | 不支持（检测到 APNG 时跳过） | 完整保留透明通道（Alpha） |
| **JPEG / JPG** | 全模式支持编码为 WebP | 无 | 纠正 EXIF 旋转方向；不保留 EXIF 元数据 |
| **WebP** | 自动上传与文档批量在开启“智能压缩 (MS-SSIM)”时支持、关闭时跳过；右键快捷压缩与弹窗均可重新编码 | 多帧动图 WebP 始终跳过 | 重新编码后记录当前原图与新 WebP 的对应关系；不保留多层版本关系 |
| **GIF** | 跳过 | 跳过 | 不转码，保留动图播放 |
| **SVG** | 跳过 | 跳过 | 矢量图不转码，保持矢量缩放 |
| **Excalidraw 与专有绘图目录** | 跳过 | 跳过 | 路径包含 `excalidraw` 或位于 `drawing/`、`drawings/` 目录中的文件跳过；普通文件名不受影响 |

### 4.2 文件大小要求
1. **自动压缩、文档批量和右键快捷压缩**：只有同时满足以下三项要求，才上传 WebP 并更新图片引用：
   - **体积下限**：输入原图 $\ge 100\text{ KiB}$ ($102,400\text{ 字节}$)，小于 100 KiB 跳过；
   - **至少节省 4 KiB**：压缩产物比原图至少小 $4\text{ KiB}$（$4,096\text{ 字节}$）；
   - **相对节省**：体积节省比例 $\ge 5\%$ ($0.05$)。
   > 任一条件未满足时，不替换原图引用。
2. **右键“压缩…”弹窗**：用户可以预览小于 100 KiB 或未达到以上节省要求的图片。点击“保存 WebP 到思源”后，插件上传 WebP 并保存记录。如果 WebP 大于原图，预览区显示“WebP 比原图更大，仍然保存”复选框；未勾选时保存按钮不可用，勾选后点击保存按钮即可继续，不另行弹出确认框。

### 4.3 图片尺寸
- 自动上传和文档批量压缩保持原图的像素宽高；
- 手动操作时，如果图片长边超过“手动压缩最大边长”（默认 4096 px），按原宽高比例缩小，不拉伸或裁切图片。

### 4.4 图片质量设置
用户可在“智能压缩 (MS-SSIM)”设置中选择质量计算方式：
1. **关闭“智能压缩 (MS-SSIM)”**：使用配置的 WebP 初始质量值（默认 `0.80`）编码；
2. **开启“智能压缩 (MS-SSIM)”**：
   - 以配置的 WebP 初始质量作为搜索起点，最终质量可能不同于该值；
   - 使用标准的 5 尺度 MS-SSIM 算法比较压缩前后的图片；处理透明图片时先计算透明度对颜色的影响；
   - 默认相似度目标为 0.99；
   - 在达到相似度目标的结果中选择文件较小的 WebP。如果质量设为 1.00 仍未达到目标，则不替换原图。

## 5. 菜单动作与用户交互

### 5.1 单图操作：压缩此图片
- **入口**：编辑器图片右键菜单；
- **行为**：使用当前质量设置在后台压缩并上传图片（支持静态 PNG、JPEG 和静态 WebP）；未达到第 4.2 节要求时不替换图片；
- **修改范围**：只替换当前选中的图片引用；同一块中的其他图片和文档其他位置不变；
- **反馈**：无弹窗打扰，完成压缩并替换引用后发送轻量状态提示，展示原体积、现体积与带符号体积变化比例（如“图片压缩成功：原体积 → 现体积（-75.0%）”）。

### 5.2 单图操作：压缩…（弹窗微调）
- **入口**：编辑器图片右键菜单；
- **界面交互**：
  - 原图与 WebP 预览图并列对比卡片布局：原图对比卡片展示缩略图与文件体积（不展示原图像素尺寸与格式字段）；WebP 预览卡片展示缩略图、文件体积、体积变化比例、像素尺寸与预计节省字节数，开启“智能压缩 (MS-SSIM)”时同时展示达成相似度与最终质量；
  - 用户可通过滑块调节 WebP 压缩质量（滑块旁显示当前百分比），通过数字输入框调节手动压缩最大边长（单位 `px`，范围 512–16384）；
  - 提供“保存后替换当前图片”复选框，默认未勾选（只保存 WebP）；点击“预览”生成对比结果后，“保存 WebP 到思源”按钮才启用；当 WebP 大于原图时，预览区显示“WebP 比原图更大，仍然保存”复选框，未勾选该复选框时“保存 WebP 到思源”按钮不可用，勾选后点击该按钮即保存，不另行弹出确认框；
  - 界面不提供 EXIF 保留设置，默认不保留 EXIF 信息；
  - 勾选“保存后替换当前图片”时，只替换当前选中的图片，替换成功后发送展示原体积、现体积与带符号体积变化比例的状态提示（变小显示 `-xx.x%`，变大显示 `+xx.x%`）；如果图片来自远程地址，先将其保存到思源，再替换为 WebP。未勾选时，本地图片只生成 WebP 并保存对应记录，不修改文档；远程图片先保存到思源并将该处引用改为本地原图，同时生成 WebP 并保存对应记录。

### 5.3 文档批量：压缩当前文档全部图片
- **入口**：文档树节点右键菜单、编辑器标题区域右键菜单、顶栏菜单；
- **行为**：
  - 读取一次当前文档，查找所有可处理的图片（包括折叠块中的图片）；只有开启“智能压缩 (MS-SSIM)”时才处理静态 WebP；动图、矢量图和专有绘图文件始终跳过；
  - 开始扫描前，若当前文档存在未销毁的活动编辑器且支持等待未保存编辑提交，先等待其挂起编辑落盘后再读取文档；更新每个块前，核验该块仍属于目标文档与笔记本且无嵌套块，并基于内核实时读回的块内容定位目标节点；当块归属变化、目标位置节点缺失或源路径与预期原值不一致时，判定为冲突并跳过；写回仅改写该目标节点的引用属性，保留同块其他文字与节点的当前内容。
  - 只更新包含目标图片且确有修改的块。其他块的编辑不影响当前块；不更新未变化的块或整篇文档。同一块有多张目标图片时，逐张检查，并根据最新内容更新；
  - 相同远程 URL 按第 3.2 节共用一次下载、一份本地原图和一份 WebP；每处图片引用分别检查并更新；
  - 进度弹窗呈现“准备资源”与“应用替换”两个阶段，实时汇报当前进度与文件名；弹窗不设独立“取消”按钮；
  - 任务启动后，切换当前文档标签页或关闭编辑器不影响后台批量任务继续执行；
  - 用户主动关闭批量进度弹窗（含按 Esc 或点击弹窗关闭按钮）时，停止本批次尚未开始的后续步骤；已上传文件、已保存记录和已提交的块修改保留，不撤销，插件重启后不继续任务；
  - 扫描完成且没有可处理图片时，关闭进度窗口并提示“当前文档没有可处理的图片。”；扫描失败时，关闭窗口并提示“文档扫描失败，未开始压缩。”；程序关闭窗口不视为用户取消；
  - 批量处理结束时发送一条结果通知：若本次文档仅命中并成功替换 1 处图片（`total === 1 && succeeded === 1`），使用与单图压缩一致的详细体积变化提示（`原体积 → 现体积（-xx.x%）`）；其余情况发送非零分项汇总通知（内部守恒统计成功、跳过、冲突、失败和结果未知的数量，面向用户的文案必显总数，其余分项仅在数量大于 0 时动态拼接展示；已中止或结果未知的项目不计为失败）。

### 5.4 白名单快捷菜单
- 文档树菜单、编辑器标题区域右键菜单与顶栏插件菜单统一提供固定文案的“当前文档图片自动压缩白名单”菜单项，并在右侧显示方框勾选视觉状态，整行点击均可切换当前文档的白名单状态；
- 勾选状态严格表示当前文档是否在白名单中，与“全局自动压缩”开关相互独立（全局开启时仍可查看与增删白名单，供关闭全局后生效）；菜单关闭后重新打开时读取最新白名单状态。

## 6. 原图记录 Dock 面板与数据管理

1. **图片压缩记录**：
   - Dock 的“图片压缩记录”面板展示两类临时核对用途的配对记录：本地压缩记录（`原图 → 最新 WebP`）与远程图片本地化记录（`图片链接 → 本地原图`）。用户确认效果无误后自行清理中间原图或压缩图，下次核验时自动移除对应本地资源已缺失的过时记录；若用户决定保留中间原图，对应的 `图片链接 → 本地原图` 记录可手动移除；常态记录规模在十余条量级；
   - 列表按最近操作时间排序，并显示来源路径（原图路径或图片链接）、产物路径（WebP 路径或本地原图路径）、操作时间、最近操作和本地文件状态（`核验中` / `存在` / `不存在` / `未知`；外链记录的来源 URL 不展示本地文件状态）；检查完成后显示最终状态；
   - 思源已登记但尚未下载的同步文件显示为 `存在`。普通资源首次检查结果不明确时，再读取一次资源：读取成功显示 `存在`，明确返回资源不存在显示 `不存在`。权限、同步、网络、超时或其他无法确认的情况显示为 `未知`；
   - 两类记录使用统一的 Dock 条目与双向交互：用户可以复制来源/产物路径、查找修改前引用（本地原图或外链 URL）并替换为修改后产物、查找修改后引用（压缩图或本地原图）并恢复为修改前来源（本地压缩记录要求原图存在，外链记录可直接恢复为原图片链接），或直接手动移除单条记录；手动移除不弹出确认框；
2. **查找和更新图片引用**：
   - 查找结果包括图片和普通资源链接，并按类型和是否支持自动更新分组；用户可点击结果跳转到文档中的位置；
   - 本地 `assets/` 路径通过内核资产引用接口反查（加密笔记本在已解锁目标笔记本内扫描）；外链 `http(s)://` 路径通过只读 SQL 辅助检索候选块并经内核实时块 DOM 核验精确匹配（来源于加密笔记本的记录在对应已解锁加密笔记本内扫描）；
   - 用户选择单处引用或执行批量替换、恢复时，只更新对应图片或链接的目标路径，不修改同一块中的其他图片、链接或文字；
   - 属性视图、数据库等无法定位到具体编辑块的位置只显示结果或提示“该位置暂不支持自动改写”，不自动更新；
   - 加密笔记本（路径带有 `?box=<notebookID>`）只有在笔记本已解锁且用户有权限时才查找或更新。笔记本锁定或无权限时，显示无法使用或 `未知`，不报告“没有引用”或“文件缺失”；
3. **记录检查与清理**：
   - 配对记录保存在插件独立的业务记录数据文件中；
   - 每次打开或切换回 Dock 标签、用户手动刷新或压缩/本地化后保存记录时，都实时核验每条记录中的本地资源、不做状态缓存，防止用户在思源或外部清理图片后列表残留过时记录。普通 `原图 → 最新 WebP` 记录在确认原图或最新 WebP 任一不存在时自动移除；外链 `图片链接 → 本地原图` 记录仅核验本地原图，仅在确认本地原图不存在时自动移除；
   - 自动清理只移除记录，不删除 `assets/` 文件，也不移除其他记录。例如，移除 `A → B` 不会影响 `B → C`；
   - 普通资源只有在再次读取时明确返回“资源不存在”，才显示为 `不存在` 并随后自动移除记录；读取成功则显示为 `存在`。权限错误、同步未就绪、其他不明确错误、网络错误或超时均显示为 `未知` 并保留记录。加密笔记本资源无法通过普通资源读取时也显示为 `未知` 并保留记录；
   - 设置重置不清除记录文件。记录最多保存 100 条；新增记录超过 100 条上限时，按最近操作时间自动淘汰最旧的临时记录（仅移出列表，不删除任何物理图片，不阻断后续压缩）。保存记录失败时，不更新文档中的图片引用，并向用户显示可复制的新资源路径。后续可在插件设置中提供查看和清空全部业务数据的功能，详见 [CORE-PRD.md](../../CORE-PRD.md) 第 9 节。
